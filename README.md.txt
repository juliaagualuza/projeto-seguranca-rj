# Análise Temporal e Espacial da Criminalidade no Estado do Rio de Janeiro (2014–2026)

Projeto desenvolvido para a disciplina de Linguagem de Programação (Análise e Visualização de Dados com Python) do 6º período de Sistemas de Informação da UniLaSalle.

## Perguntas de Pesquisa
- **RQ1:** Como evoluíram as ocorrências de roubo de rua no estado?
- **RQ2:** Quais municípios concentram mais ocorrências em relação à população?
- **RQ3:** Existe sazonalidade mensal nos registros?

## Como Executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o ETL: `python src/etl.py`
