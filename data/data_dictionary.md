# Dicionário de Dados

## Projeto
Análise Temporal e Espacial da Criminalidade no Estado do Rio de Janeiro (2014–2026).

## Fonte dos dados
Instituto de Segurança Pública do Estado do Rio de Janeiro (ISP-RJ).

## Descrição
Este arquivo documenta as variáveis utilizadas na análise dos dados de criminalidade.

## Variáveis

As variáveis serão documentadas conforme as colunas presentes no arquivo CSV original.

| Variável | Descrição | Tipo |
|---|---|---|
| Município | Município onde ocorreu o registro | Texto |
| Ano | Ano de referência do registro | Numérico |
| Mês | Mês de referência do registro | Numérico |
| Indicador | Tipo de ocorrência criminal | Texto |
| Quantidade | Número de registros | Numérico |
